Isi dari planningnya adalah sebagai berikut:

buat tabel session:
id integer auto increment primary key
token varchar(255) not null unique (isinya UUID untuk token user yang login)
user_id integer not null (relasi ke user yang login)
created_at datetime default current_timestamp 

buatkan API untuk login

Endpoint: POST /api/users/login
Body:
{
  "email": "[EMAIL_ADDRESS]",
  "password": "password"
}
Response Success:
{
  "message": "User login successfully",
  "session": {
    "token": "UUID",
    "user_id": 1,
    "created_at": "2022-01-01T00:00:00.000Z"
  }
} 

Response error:
{
  "error": "Email atau Password salah",
  "message": "User dengan email [EMAIL_ADDRESS] tidak terdaftar atau password salah",
  "code": "401"
}

Response Error lain:
{
  "error": "Internal Server Error",
  "message": [isi pesan error aslinya], //sesuaikan dengan error yang terjadi di aplikasi
  "code": "500" //jika code error nya bukan 500 ya sesuaikan juga 
}

Struktur folder di dalam src
- routes : ini berisi routing untuk ElysiaJS
- services : ini berisi logic bisnis aplikasi

Struktur file
- routes : menggunakan format misal users-route.ts
- services : menggunakan format misal users-service.ts
